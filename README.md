# Catch That Flight

A small browser game set in a stylized Paris airport. Help Camille reach Gate B12 before boarding closes.

[Play online](https://liuxiaotong1.github.io/catch-that-flight/)

## Controls

- Arrow keys or A/D: move
- Space: jump over luggage
- Hold Shift: sprint
- P or Escape: pause
- R: restart
- Music-note button: mute

On smaller screens, use the on-screen controls. Tap Sprint to toggle it.

Navigate around travelers and strollers, avoid coffee spills, and take a call from maman. Catch your flight, or spend the night at Gate B12.

The game is a self-contained HTML file. Audio starts after pressing Play and uses browser speech and synthesized sound. Voices vary by device. Google fonts are optional and fall back to system fonts offline.
